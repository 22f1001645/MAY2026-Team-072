<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine → developer database | `flask db upgrade` executes revision files as arbitrary Python against the database |
| PyPI → backend runtime | a new third-party dependency enters the import graph of every request |
| model definitions → physical schema | autogenerate translates Python declarations into DDL that no human wrote |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
