# 03-03: Mega Meetup Label, Meetup Head Reassignment & Admin Queue Enrichment

**Phase**: 3 — Proposal Collaboration, Team Roster & Budget Guardrails
**Requirements**: PROPOSAL-03, PROPOSAL-04, PROPOSAL-05
**Depends on**: 03-02-PLAN.md

## Goal

Prove that (1) `Activity.is_mega_meetup` is `True` when ≥3 orgs have accepted the collaboration invite, (2) the admin approval queue's `GET /proposals/<id>` response includes `collaborators` and `team_members`, and (3) the Meetup Head can be reassigned to any user by the proposer or admin before campaign goes live.

## Tracer Scope

**In scope**: `is_mega_meetup` property, `to_dict(detail=True)` enrichment with collaborators + team members, `N+1` fix on the proposals query, the `reassign-meetup-head` endpoint, and all tests.  
**Not in scope**: Frontend rendering of the label or roster (03-04), campaign live-gate enforcement (Phase 5, CAMPAIGN-06), organisation profile (Phase 4).

### Task 1: Add `is_mega_meetup` Property to Activity Model
- **type**: `tracer`
- **reversibility**: `reversible`
- **files**:
  - `backend/app/models/__init__.py` [MODIFY]

#### Implementation

In `Activity`'s class body (before `to_dict`), add:

```python
from ..constants import COLLAB_ACCEPTED, MEGA_MEETUP_THRESHOLD

@property
def is_mega_meetup(self) -> bool:
    """PROPOSAL-03: True when ≥3 collaborating orgs have accepted the invite.

    Computed dynamically so it tracks real-time accept/decline state without
    a stored flag that would drift. MEGA_MEETUP_THRESHOLD=3 is defined in
    constants.py."""
    return (
        sum(1 for c in self.collaborators if c.status == COLLAB_ACCEPTED)
        >= MEGA_MEETUP_THRESHOLD
    )
```

Add `"is_mega_meetup": self.is_mega_meetup` to `Activity.to_dict()` base dict (before the `if detail:` block):

### Task 2: Fix N+1 on `proposals_by_status` Query
- **type**: `expansion`
- **reversibility**: `reversible`
- **files**:
  - `backend/app/repositories/repos.py` [MODIFY]

#### Implementation

Locate `ActivityRepository.proposals_by_status` in `repos.py`. Add `joinedload` for `Activity.collaborators`, `Activity.team_members`, and `Activity.budget_lines` to prevent N+1 queries when the admin queue lists many proposals.

```python
from sqlalchemy.orm import joinedload

class ActivityRepository:
    ...
    @staticmethod
    def proposals_by_status(status: str):
        return (
            Activity.query
            .join(Activity.proposal)
            .filter(Proposal.status == status)
            .options(
                joinedload(Activity.proposal),
                joinedload(Activity.collaborators),
                joinedload(Activity.team_members),
                joinedload(Activity.budget_lines),
            )
            .order_by(Activity.created_at.desc())
            .all()
        )
```

If `joinedload` is already imported elsewhere in `repos.py`, reuse it. Otherwise add the import from `sqlalchemy.orm`.

```python
def reassign_meetup_head(activity, new_user_id: str, actor) -> dict:
    """PROPOSAL-05: reassign the Meetup Head to any user, by proposer or admin.

    The live-campaign gate (cannot reassign after the campaign goes live) is
    intentionally a no-op stub here — the Campaign model lands in Phase 5
    (CAMPAIGN-06). The comment below must be filled when that model exists.

    The old Meetup Head row is DELETED (not demoted). If the proposer wants the
    former head to remain in another role, they add a separate team member row."""
    new_user = User.query.get(new_user_id)
    if not new_user:
        raise ApiError("User not found", "user_not_found", 404)

    # Phase 5 live-campaign gate — fill this stub when Campaign model exists:
    # campaign = Campaign.query.filter_by(activity_id=activity.id).first()
    # if campaign and campaign.status == CAMPAIGN_LIVE:
    #     raise ApiError(
    #         "Cannot reassign Meetup Head after the campaign has gone live",
    #         "campaign_live",
    #         409,
    #     )

    # Remove the existing Meetup Head row (the partial unique index makes at most one)
    old = ActivityTeamMember.query.filter_by(
        activity_id=activity.id, role=TEAM_ROLE_MEETUP_HEAD
    ).first()
    if old:
        db.session.delete(old)
        db.session.flush()  # flush before adding new row to avoid transient constraint violation

    db.session.add(ActivityTeamMember(
        activity_id=activity.id,
        user_id=new_user_id,
        role=TEAM_ROLE_MEETUP_HEAD,
        added_by=actor.id,
    ))
    AuditRepository.record(
        "proposal",
        activity.id,
        f"Meetup Head reassigned to {new_user.name}",
        actor,
    )
    db.session.commit()
    return {"activity_id": activity.id, "new_meetup_head_user_id": new_user_id}
```

```python
class TestMegaMeetup:
    @pytest.fixture()
    def activity_with_two_accepted(self, client, auth_headers, organiser_with_por,
                                   valid_payload, seed_orgs, collab_org_authority,
                                   db_session):
        """A proposal with 1 primary + 2 accepted collaborating orgs (total=3 accepted
        including primary, but only 2 secondary accepted — not yet ≥3 secondary)."""
        from backend.app.models import ActivityCollaborator
        from backend.app.constants import COLLAB_ACCEPTED
        collab1 = seed_orgs[1]
        collab2 = seed_orgs[2]
        valid_payload["collaborating_org_ids"] = [collab1.id, collab2.id]
        resp = client.post("/api/v1/activities", json=valid_payload,
                           headers=auth_headers(organiser_with_por))

        activity_id = resp.json["id"]
        # Accept both manually in DB for test setup speed
        for row in ActivityCollaborator.query.filter_by(
            activity_id=activity_id, is_primary=False
        ).all():
            row.status = COLLAB_ACCEPTED
        db_session.commit()
        return activity_id

    def test_is_mega_meetup_false_with_two_accepted_secondary(
        self, client, auth_headers, activity_with_two_accepted, seed_users
    ):
        """PROPOSAL-03: primary + 2 accepted secondary = 3 total accepted → True."""
        # NOTE: primary counts! So 1 primary + 2 secondary accepted = 3 ≥ 3 = True
        from backend.app.models import Activity
        from backend.app.constants import MEGA_MEETUP_THRESHOLD
        activity = Activity.query.get(activity_with_two_accepted)
        # Primary (accepted) + 2 secondary (accepted) = 3 total accepted
        assert activity.is_mega_meetup is True

    def test_is_mega_meetup_false_with_fewer_than_threshold(
        self, client, auth_headers, organiser_with_por, valid_payload,

        from backend.app.models import Activity

        valid_payload["collaborating_org_ids"] = [collab.id]

                           headers=auth_headers(organiser_with_por))
        assert resp.status_code == 201
        activity = Activity.query.get(resp.json["id"])
        # Primary (accepted) + 1 secondary (pending) = 1 accepted < 3
```
