<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Flask API | An authenticated POR holder supplies an `org_id` in the URL path and free text in the body; both are untrusted. |
| caller identity → organisation identity | The JWT says who; only `can_manage_org` says which organisations that person may act on. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Elevation of Privilege | `PATCH /orgs/<org_id>/profile` | high | mitigate | `can_manage_org_required`; the boundary is org **id** identity, never name or city. Negative test `cross_org_403` asserts 403 + `code == "forbidden"` for a Secretary of A against org B. |
| T-04-02 | Elevation of Privilege | route registration | high | mitigate | The URL param is spelled `org_id`; a misspelling silently degrades to 404-for-everyone while the RBAC suite stays green. Enforced by an `admin_any_org` 200 assertion (a 404 there is the warning sign) and a `grep -c organisation_id == 0` acceptance criterion. |
| T-04-03 | Spoofing | `GET /orgs/<org_id>/profile` | low | accept | The read route is `auth_required` only: any logged-in user may read any organisation's public profile. This is the intended product behaviour — the profile *is* public within the app — and no field it returns is sensitive. Editability is never inferable from the payload (P-06). |
| T-04-04 | Denial of Service | `bio` free text | medium | mitigate | `validate.Length(max=1000)` on `OrgProfileSchema.bio`; `organisations.bio` is an unbounded `db.Text` and nothing upstream bounds it (UI-SPEC contract addition 3). |
| T-04-05 | Repudiation | profile mutation | medium | mitigate | `AuditRepository.record("organisation", org.id, ..., actor)` in the same transaction as the change, before `db.session.commit()`, matching the three existing call sites in `org_service.py`. |
| T-04-06 | Tampering | unrouted endpoint | medium | mitigate | `test_blueprint_registration.py` walks `app/controllers/` and asserts every Blueprint is in `ALL_BLUEPRINTS` — an endpoint that silently 404s is a control that silently does not exist. |
</threat_model>
