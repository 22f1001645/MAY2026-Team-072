1. Helper `_assert_channel_open(activity)` checking `activity.status == EVENT_LIVE`.
2. `create_poll(activity_id, question, options, closes_at, current_user)`:
   - Verify activity exists and call `_assert_channel_open(activity)` — poll creation is scoped to the event's live/registration window (CHAT-01), same as voting.
   - Insert `EventPoll` with `activity_id=activity_id`, `question=question`, `options=options`, `closes_at=closes_at`, `created_by=current_user.id`, `status=POLL_OPEN`.
   - Call `AuditRepository.record("poll", poll.id, "Poll created", current_user, note=question)`.
   - Commit and return `poll`.
3. `list_polls(activity_id, viewer_id=None)`:
   - Query all `EventPoll` for `activity_id` ordered by `created_at DESC` with `joinedload(EventPoll.votes)`.
   - For each poll:
     - Count votes per `option_index` in range `len(poll.options)`.
     - Find `my_vote` if `viewer_id` matches any `vote.user_id`.
     - Return list of dicts with `to_dict()` keys + `vote_counts: list[int]` + `my_vote: int | None`.
4. `cast_vote(activity_id, poll_id, option_index, current_user)`:
   - Verify activity exists and call `_assert_channel_open(activity)`.
   - Verify caller is registered attendee (`RegistrationRepository.find(activity_id, current_user.id)` is not None) or organiser.
   - Fetch poll; verify `poll.status == POLL_OPEN`.
   - Verify `0 <= option_index < len(poll.options)`.
   - Insert `EventPollVote(poll_id=poll_id, user_id=current_user.id, option_index=option_index)`.
   - Wrap `db.session.commit()` in `try...except IntegrityError:` -> raise `ApiError("You have already voted on this poll", "already_voted", 409)`.
   - Votes are not audit-logged (routine attendee activity, not a moderation action — matches the existing convention where task CRUD/attendance writes skip AuditLog too).
5. `close_poll(activity_id, poll_id, current_user)`:
   - Fetch poll, verify it belongs to `activity_id`.
   - Set `poll.status = POLL_CLOSED`.
   - Call `AuditRepository.record("poll", poll.id, "Poll closed", current_user)`.
   - Commit and return poll.

Note: `close_poll` and `respond_query` (08-02) intentionally do NOT call `_assert_channel_open` — organisers must be able to close a poll or answer a lingering question after the event ends. Only `create_poll` and the attendee-facing `cast_vote`/`submit_query` are gated to `EVENT_LIVE`.

```python
from flask import Blueprint, g, jsonify, request
from ..errors import ApiError
from ..rbac import auth_required, can_manage_activity_required
from ..schemas import PollCreateSchema, PollVoteSchema
from ..services import channel_service

channel_bp = Blueprint("channel", __name__, url_prefix="/api/v1")

@channel_bp.post("/events/<activity_id>/polls")
@can_manage_activity_required
def create_poll(activity_id):
    data = PollCreateSchema().load(request.get_json() or {})
    poll = channel_service.create_poll(
        activity_id,
        data["question"],
        data["options"],
        data.get("closes_at"),
        g.current_user,
    )
    return jsonify(poll.to_dict()), 201

@channel_bp.get("/events/<activity_id>/polls")
@auth_required
def list_polls(activity_id):
    polls = channel_service.list_polls(activity_id, g.current_user.id if g.current_user else None)
    return jsonify(polls), 200

@channel_bp.post("/events/<activity_id>/polls/<poll_id>/vote")
@auth_required
def cast_vote(activity_id, poll_id):
    data = PollVoteSchema().load(request.get_json() or {})
    vote = channel_service.cast_vote(activity_id, poll_id, data["option_index"], g.current_user)
    return jsonify(vote.to_dict()), 201

@channel_bp.patch("/events/<activity_id>/polls/<poll_id>/close")
@can_manage_activity_required
def close_poll(activity_id, poll_id):
    poll = channel_service.close_poll(activity_id, poll_id, g.current_user)
    return jsonify(poll.to_dict()), 200
```
