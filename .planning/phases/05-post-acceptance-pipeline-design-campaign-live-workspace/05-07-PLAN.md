The copy handler passes the `registrationUrl` **prop** to `navigator.clipboard.writeText`, then
`addToast('Link copied!', 'success')`. It must not read the rendered text node and must not
build the URL from `window.location.origin` — the on-screen value is truncated by CSS, and D-12
makes the URL shape a contract the server owns. This is the one substantive difference from the
`EventDetail.tsx` block whose shape is otherwise copied verbatim.

`Generate Link` in place of the Copy button and `text-graytext-mid` `—` in place of the URL.

`onGenerate`, `addToast('Failed to generate link. Try again.', 'error')`.

| Boundary | Description |

| anonymous browser → SPA route | **New in this plan.** The client renders a page for a visitor with no session for the first time |

| component → `api.ts` | The single wire seam; no component assembles a URL |
