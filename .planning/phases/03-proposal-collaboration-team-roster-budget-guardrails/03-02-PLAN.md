# 03-02: Collaborator Invite Flow & Notifications

**Phase**: 3 — Proposal Collaboration, Team Roster & Budget Guardrails
**Requirements**: PROPOSAL-01, PROPOSAL-06
**Depends on**: 03-01-PLAN.md

## Goal

Prove that a proposal can name collaborating organisations — each written as a `PENDING` `ActivityCollaborator` row with authority-holder notifications — and that a collaborating org's Secretary/Deputy Secretary/RC can accept or decline the invite through a dedicated endpoint, with only `ACCEPTED` collaborators counting toward downstream features.

## Tracer Scope

**In scope**: Writing `ActivityCollaborator` rows at submission time (including the always-`ACCEPTED` primary), the collaborator respond endpoint, authority-holder notification dispatch, and tests.  
**Not in scope**: Mega Meetup label (03-03), admin queue columns (03-03), frontend (03-04), campaign live-gate on reassignment (Phase 5).

```python
def _notify_collab_invite(activity: Activity, primary_org, collab_org):
    """PROPOSAL-06: fire a notification to every active ORG_MANAGER_PORS holder
    in collab_org, informing them they have been invited to collaborate.

    Authority holders are determined by the same ORG_MANAGER_PORS set used by
    can_manage_org — the same people who will later accept or decline the invite.
    Notification bodies avoid storing accept/decline links; the UI routes to the
    event detail page where the respond button lives."""
    from ..constants import ORG_MANAGER_PORS
    authority_user_ids = {
        m.user_id
        for m in collab_org.memberships
        if any(p.active and p.por_type in ORG_MANAGER_PORS for p in m.pors)
    }
    for uid in authority_user_ids:
        _notify(
            uid,
            activity.id,
            "collaboration_invite",
            f"Collaboration invite: {activity.title}",
            f"{primary_org.name} has invited {collab_org.name} to collaborate on "
            f"'{activity.title}'. Accept or decline from the event detail page.",
        )
```

### Task 4: Add `respond_collab` Service Function
- **type**: `expansion`
- **reversibility**: `reversible`
- **files**:
  - `backend/app/services/proposal_service.py` [MODIFY]

#### Implementation

```python
def respond_collab(collab, new_status: str):
    """PROPOSAL-06: accept or decline a collaboration invite.

    Only PENDING invites can be responded to — re-responding to an already-decided
    invite is a 409. The caller (controller) must have already verified that the
    acting user holds can_manage_org authority over collab.org before calling this."""
    if collab.status != COLLAB_PENDING:
        raise ApiError(
            "This collaboration invite has already been responded to",
            "already_responded",
            409,
        )
    if new_status not in (COLLAB_ACCEPTED, COLLAB_DECLINED):
        raise ApiError(
            "Status must be 'accepted' or 'declined'",
            "invalid_status",
            400,
        )
    from datetime import UTC
    collab.status = new_status
    collab.responded_at = datetime.now(UTC)
    db.session.commit()
    return collab
```

```python
from ..rbac import auth_required, can_manage_org
from ..models import ActivityCollaborator
from ..schemas import CollabRespondSchema

@proposal_bp.post("/activities/<activity_id>/collaborators/<collab_id>/respond")
@auth_required
def respond_collab(activity_id, collab_id):
    """PROPOSAL-06 — accept or decline a collaboration invite.

    Guard: the acting user must hold can_manage_org authority over the collaborating
    organisation (Secretary/Deputy Secretary/RC of that specific org). We do NOT use
    @can_manage_org_required here because the URL param is collab_id (the invite row's
    id), not org_id — org_scoped() reads from URL kwargs, so we load the collab row
    first and check inline."""
    collab = ActivityCollaborator.query.filter_by(
        id=collab_id, activity_id=activity_id
    ).first()
    if not collab:
        raise ApiError("Collaboration invite not found", "not_found", 404)

    from ..repositories.repos import OrgRepository
    collab_org = OrgRepository.by_id(collab.org_id)
    if not can_manage_org(g.current_user, collab_org):
        raise ApiError(
            "Authority over the collaborating organisation is required",
            "forbidden",
            403,
        )

    data = CollabRespondSchema().load(request.get_json() or {})
    updated = proposal_service.respond_collab(collab, data["status"])
    return jsonify(updated.to_dict()), 200
```
