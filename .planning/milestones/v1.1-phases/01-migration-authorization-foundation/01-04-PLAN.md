| Boundary | Description |
|----------|-------------|
| environment (`DATABASE_URL`) → destructive database operation | one exported variable is the entire distance between wiping a scratch file and wiping a deployed database |
| autogenerated DDL → live schema | Alembic writes the migration; a human must have read it before it runs |
| migration chain ↔ `alembic_version` | if these disagree, every teammate's next upgrade fails in a way that is hard to diagnose |
