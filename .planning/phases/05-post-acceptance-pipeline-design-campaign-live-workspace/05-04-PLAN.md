<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/api/v1/activities/<id>/tasks` | Untrusted JSON; every crew member of a live activity writes here |
| `can_manage_activity` → task rows | Crew membership is the authorization identity; it confers nothing beyond this activity |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-20 | Elevation of Privilege | reading or writing another activity's board | high | mitigate | `@can_manage_activity_required` on all four routes plus the per-row `activity_id` identity check in `update_task` / `delete_task`; asserted by the cross-activity 404 case |
| T-05-21 | Information Disclosure | a workspace readable before the campaign is published | high | mitigate | `assert_campaign_live` on every task service function, including the read; `test_tasks_403_when_campaign_not_live` covers absent and draft campaigns, not just absent |
| T-05-22 | Tampering | an arbitrary status value persisting into the board | medium | mitigate | `validate.OneOf(TASK_STATUSES)` imported from constants; a bad value is a 422 from the central handler and never reaches a column |
| T-05-23 | Denial of Service | unbounded task title / description text | low | mitigate | `Length(max=200)` on the title matching the declared column width; `Range(min=0)` on position |
| T-05-24 | Tampering | a partial PATCH silently blanking `deadline` or `assignee_id` | low | mitigate | `update_task` applies only keys whose loaded value is not `None`; asserted explicitly |
| T-05-SC | Tampering | package-manager installs | high | accept | This plan runs no `pip install` / `npm install`; Phase 5 adds zero dependencies |
</threat_model>
